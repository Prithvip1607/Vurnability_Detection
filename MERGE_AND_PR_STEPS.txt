## STEP 2 — Push Your Branch to GitHub (if not already pushed)

    git push origin Jayant01

Confirm it is pushed by visiting:
    https://github.com/Prithvip1607/Vurnability_Detection/tree/Jayant01

---

## STEP 3 — Raise a Pull Request (PR) on GitHub

1. Go to: https://github.com/Prithvip1607/Vurnability_Detection
2. You will see a yellow banner: "Jayant01 had recent pushes" — click "Compare & pull request"
   OR manually go to:
   https://github.com/Prithvip1607/Vurnability_Detection/pull/new/Jayant01

3. Fill in the PR form:
   - Title:     "Jayant01: Flask Dashboard + Zero-Day Detection UI + Audit Log"
   - Base:      main
   - Compare:   Jayant01
   - Description (copy-paste this):

     ## What was added in this PR

     - app.py — Flask backend with 3 API endpoints:
         /api/vulnerabilities  → returns all 800 entries
         /api/zero-days        → returns only zero-day entries (69 found)
         /api/stats            → returns severity counts, targets, vuln types

     - static/index.html — Dark theme Zero-Day Dashboard:
         - Stats cards (total, zero-days, HIGH severity, targets)
         - Search bar + filters (severity, target, vuln type)
         - Table with click-to-expand detail modal
         - Color coded severity badges

     - audit_vulnerability_project.txt — Full audit log of all steps taken

     ## How to Run
         pip3 install flask
         python3 app.py
         Open: http://localhost:5000

4. Click "Create Pull Request"

---

## STEP 4 — Merge the PR into Main (Repo Owner does this)

Option A — Merge via GitHub UI:
1. Open the PR on GitHub
2. Click "Merge pull request"
3. Click "Confirm merge"
4. Optionally click "Delete branch" after merge

Option B — Merge via Terminal (if you have write access to main):

    git checkout main
    git pull origin main
    git merge Jayant01
    git push origin main

---

## STEP 5 — Verify Merge

After merge, confirm on GitHub:
    https://github.com/Prithvip1607/Vurnability_Detection/tree/main

You should see app.py, static/index.html, audit_vulnerability_project.txt in main branch.
